---
title: Give a name a new value
start_error: E0501
error_note: Line 2 declared `count` with `let`, so line 3 can't assign to it.
---

Line 3 adds 1 to `count`.
Before you run it, decide whether `lughac` allows that.
Then press Run.

A `let` can't be given a new value unless it's declared `let mut`.
Add `mut` on line 2 and run again, or press Solve.
