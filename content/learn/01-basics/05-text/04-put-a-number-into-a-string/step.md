---
title: Put a number into a string
start_error: E0404
---

Line 3 tries to join `"points: "` and `points` with `+`.
Before you run it, decide whether that compiles.
Then press Run.

`+` only joins two strings, and `points` is an `i64`.
Put the number in braces instead, `"points: {points}"`, or press Solve.
