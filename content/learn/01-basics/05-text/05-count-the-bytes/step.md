title: Count the bytes
---

Line 3 prints `name.len`.
Before you run it, decide what it prints for `Zoë`.
Then press Run.

It prints `4`: `.len` counts bytes, and `ë` takes two of them.
Line 4 counts characters with `char_count()`, so it prints `3`.
`.len` is read like a field, without parentheses, and `char_count()` is a method you call.
