---
title: The main function
---

A Lugha program starts at `main`, and this one has a single line: `println` prints what it's given, then a newline.
Line 1 is a doc comment, `/** … */`, which editors show beside the item that follows it.
Press Run.

The output ends with the exit code, 0.
This `main` returns nothing, so the program ends with 0 when it reaches the end of `main`.
