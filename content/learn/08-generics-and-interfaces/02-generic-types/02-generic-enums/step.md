Enums take type parameters in the same place.
`List<T>` on lines 1 to 4 is the list from Recursive enums, which held only numbers, now holding any type.
Line 14 builds a list of strings, and `size` on line 6, generic itself, counts it.
`Option<T>`, which `first` gave back in Generic functions, is declared this way too.
