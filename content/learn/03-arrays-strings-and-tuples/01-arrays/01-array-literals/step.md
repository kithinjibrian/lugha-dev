---
title: Array literals
---

An array holds values of one type in order, written in square brackets, as on line 2.
Line 3 uses the other way to write one, `[value; count]`.
What will `[0; 4]` hold?
Press Run.

It prints `[0, 0, 0, 0]`: four elements, each a copy of `0`.
`.len` on line 6, written without parentheses, is the number of elements.
`scores` is an `i64[]`, an array of `i64`.
